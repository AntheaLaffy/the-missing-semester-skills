# 练习：提出好问题

对应课程 Collaboration 一讲的练习，复习用。

1. **对比 Stack Overflow 问题。** 打开 Stack Overflow，找一个你熟悉技术领域内获得高票回答的问题。再找一个被关闭或大量被点踩的问题。按照本 skill 的建议对比它们：能否预见哪个问题更可能得到好答案？
