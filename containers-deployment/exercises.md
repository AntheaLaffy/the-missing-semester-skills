# 练习：容器与部署

对应课程第 6 讲的练习（节选，按主题归入本 skill），复习用。

1. **compose 跑课程网站**。安装 Docker，用 docker compose 在本地构建并运行 Missing Semester 课程网站。
2. **Dockerfile + Redis**。给一个简单的 Python 应用写 Dockerfile；再写一个 docker-compose.yml，让应用和一个 Redis 缓存一起运行。
3. **GitHub Pages**。用 GitHub Pages 做一个网站。附加（非学分）：给它配置自定义域名。
