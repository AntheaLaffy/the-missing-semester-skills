# 渐进式学习 The Missing Semester

主线：你学的是「代码之外的另一半工程能力」。本 skill 不复制课程内容——仓库里 28 个 skill 就是课程单元，内容只维护一份；本 skill 负责带节奏：**最小单元、紧反馈、有状态、跨会话渐进**。教学法约定与 teach skill 同源（检索练习、间隔、交错、最近发展区 ZPD）。

## 工作区（.missing-semester/）

- 状态全部落在**当前工作目录**的 `.missing-semester/` 下，**永不写仓库目录**——仓库是只读内容源，用户可能把它装在 `.claude/skills`、`.agents/skills` 或任意位置。用户在哪学，进度就在哪。
- 文件布局：
  - `MISSION.md` — 学习动机。首次启动先盘问：为什么学这门课、最想解决什么实际问题？动机变化时更新它并记一条学习记录。
  - `progress.md` — 28 个单元的进度表（未学/学习中/已学）、自测得分、待复习池（答错的单元）。
  - `learning-records/0001-*.md` — 每条记录一个非显然的领悟（格式同 teach skill 的 learning-record）。
  - `NOTES.md` — 用户偏好（讲解深度、例子语言、节奏），每次进入先读，边教边补。
- 首次启动顺序：读 `NOTES.md` → 没有 `MISSION.md` 就先盘问动机并落盘 → 从第一单元开始。

## 单元循环（每单元跑一遍）

1. **动机**：一句话说清这个 skill 解决什么问题，往 MISSION 上靠。
2. **最小知识**：读该单元的 `SKILL.md`，只讲本单元要点——工作记忆有限，不展开邻接话题；知识出处引用对应讲义页。
3. **练习**：从该单元的 `exercises.md` 选 1 道**可验证**的题；用户亲手做（终端/代码里），做完跑命令或对比预期输出，**即时验证**——反馈立等可取。
4. **自测**：出 2–3 道检索题，让用户凭回忆作答（不给选项、不给格式线索）；即时判分并解释为什么。
5. **记录**：写 `learning-records/000N-*.md`（本单元一个非显然的领悟）；更新 `progress.md`——单元标记已学、记自测得分、错题进待复习池。

## 复习层（每次会话开头）

- 从已学单元做**间隔回抽**：抽 2–3 道题（待复习池优先，顺带交错相邻讲的主题）。
- 答错的单元重新进待复习池，并重讲该单元要点。

## 推进（ZPD）

- 默认顺序见同目录 `CURRICULUM.md`（9 讲 × 28 单元，按课程顺序）。
- 下一单元 = 已学列表的末尾 + 1；连续自测不理想就**回退重讲上一单元**，而不是硬推。
- 允许点名跳跃：「学习第 3 讲」「只学 regex」「复习」。

## 智慧出口

- 学完去社区验证：OSSU Discord 的 #missing-semester-forum 提问、看别人怎么用——真实世界的交互才出智慧。
